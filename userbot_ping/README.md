# Юзербот-пингер

Держит основного бота "живым" на бесплатном хостинге с отключением по неактивности:
раз в 10 минут шлёт `/ping` в личку боту с твоего личного Telegram-аккаунта.

## Установка и первый запуск

```
cd userbot_ping
pip install -r requirements.txt --break-system-packages
python ping_bot.py
```

При первом запуске Telethon попросит:
1. Номер телефона (в международном формате, например +7...)
2. Код подтверждения — придёт в Telegram (в "Избранное"/системным сообщением)
3. Пароль двухфакторной аутентификации — если она включена на аккаунте

После этого рядом появится файл `ping_session.session` — он хранит сессию, и при
следующих запусках вводить код заново не понадобится.

## Куда это деплоить

**НЕ на тот же хостинг, где крутится сам бот** — если этот хостинг заснёт, уснёт и
пингер вместе с ботом, и пинговать станет некому. Варианты:
- Свой ПК/ноутбук, который постоянно включён.
- Отдельный always-on сервис (VPS, другой бесплатный хостинг без сна, Raspberry Pi
  дома и т.п.).

## Если не помогает

Если хостинг бота засыпает именно по неактивности HTTP-порта (так работает
бесплатный тариф Render/Railway и похожих) — сообщение в личку боту эту "спячку"
не остановит, потому что бот принимает Telegram-сообщения через long polling, а не
через HTTP. В этом случае в `main.py` бота уже поднят лёгкий HTTP-эндпоинт
(`HEALTHCHECK_PORT` в `config.py`, отвечает `ok` на `GET /`) — настрой внешний
пинг на него (например через uptimerobot.com или cron-job.org, раз в 10 минут) —
это и будет держать активным именно HTTP-порт.
